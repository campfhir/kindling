## 1. Hierarchy (both 270 and 271)

```
ST / BHT                                   (header, no loop)
└─ 2000A Information Source Level   HL03=20   (HL02 not used: top of the tree)
   ├─ 2100A Information Source Name  NM1
   └─ 2000B Information Receiver Level  HL03=21   (HL02 = HL01 of its 2000A)
      ├─ 2100B Information Receiver Name  NM1
      └─ 2000C Subscriber Level  HL03=22   (HL02 = HL01 of its 2000B)
         ├─ 2100C Subscriber Name  NM1
         │  └─ 2110C  270: Subscriber Eligibility/Benefit Inquiry (EQ)
         │            271: Subscriber Eligibility/Benefit Information (EB)
         │     ├─ 2115C  271 only: Subscriber Eligibility/Benefit Additional Information (III)
         │     └─ LS*2120 … 2120C Subscriber Benefit Related Entity Name (NM1) … LE*2120   (271 only)
         └─ 2000D Dependent Level  HL03=23   (HL02 = HL01 of its 2000C; HL04 always 0)
            └─ 2100D Dependent Name  NM1
               └─ 2110D  (EQ in 270 / EB in 271)
                  ├─ 2115D  (271 only, III)
                  └─ LS*2120 … 2120D Dependent Benefit Related Entity Name … LE*2120   (271 only)
SE
```

Evidence:
- HL03 codes 20 / 21 / 22 / 23 on the 2000A / 2000B / 2000C / 2000D HL rows; HL02 is `N/U` in 2000A and `R` in 2000B, 2000C and 2000D, in both the 270 and 271 (XW pp. 1–5, 22–29).
- HL04 values: 270 2000A `1`, 2000B `1`, 2000C `0, 1`, 2000D `0`. 271 2000A `0,1`, 2000B `0, 1`, 2000C `0, 1`, 2000D `0` (XW). NV: HL04 `0 = 'No Subordinate HL Segment in This Hierarchical Structure'`.
- X2a (270, dependent): four HL levels 20, 21, 22, 23 with HL04 `1` on the subscriber level and `0` on the dependent level; the dependent HL (ID 4) names the subscriber HL (ID 3) as its parent, and its 2100D NM1 has NM101 `03` and no NM108/NM109.
- X1a (270, subscriber): HL levels 20, 21, 22 with HL04 `0` on the subscriber level, then TRN, NM1 (NM101 `IL`), DMG, DTP (DTP01 `291`) and one EQ.
- 2110 sits under 2100, and 2115 and the LS/2120/LE group sit under 2110: XW loop column (2110C EQ/EB starts a loop "99"/">1" after the 2100C segments; III starts 2115C; LS is in 2110C; NM1 starts 2120C). RFI1807: *"The 005010X279A1 Technical Report Type 3 specifies that the LS Loop Header and LE Loop Trailer segments occur only once within each 2110C loop. The LS/LE loop header and trailer serve as the boundary encapsulating all the repeats of the 2120C loops within one 2110C loop."*

## 5. Could NOT confirm from an allowed public source

1. **X12 Glass.** X12 Glass is behind a paid license (noted by the maintainer, 2026-10-30), so it is not a free public source for this ledger. It was also unreachable from the research session: `https://glass.x12.org/` failed through the sandbox proxy (`CONNECT tunnel failed, response 502`, recorded as a gateway `connect_rejected`). The x12.org marketing page (https://x12.org/products/glass) loads but has no structure content. Nothing in this ledger comes from Glass, and no free X12 base-standard 270/271 table was found on x12.org.
2. **The TR3's own segment names in mixed case.** XW prints implementation names in upper case. Title-case wording is confirmed only where HETS, NV, MD, SD or MA print the same name. These names come from XW alone:
   - 270: 2100B REF/N3/N4/PRV, 2100C/D PRV ("Provider Information"), INS, HI, all of 2000D/2100D/2110D except the HL and NM1, and the 2110C AMT/III/REF/DTP.
   - 271: 2100A PER, 2100B N3/N4/PRV, 2100C/D INS/HI/MPI/PRV, 2115C/D III, 2120C/D N3/N4/PRV and all of 2000D.
   Some XW names are clipped or wrapped ("ELIGIBILITY/BENEFI T", "SUBSCIBER"), and the 2115D III and 2100D MPI names lack the "DEPENDENT" prefix.
3. **Code meanings.** XW lists code *values* only. Meanings are confirmed only where a guide prints them: BHT02 `13 = Request` (NV, MD); NM101 `PR`, `1P`; NM102 `2`; NM108 `PI`, `MI`, `XX`; TRN01 `1`, `2`; HL04 `0`; EB01 `R = 'Other or Additional Payer'`; REF01 `1L = 'Group or Policy Number'`; DTP01 `291 = 'Plan'`, `307 = 'Eligibility'` (NV). These are **unconfirmed**:
   - BHT02 `01`, `06` and `11`;
   - HL04 `1`;
   - NM101 `IL`, `03` and the 2120C codes;
   - HL03 code names beyond the loop names.
4. **The rest of the 271 2110D DTP01 code list.** A page break in XW cuts it off after `346`. It probably matches 2110C, but that is not confirmed.
5. **271 2110D EB and HSD usage.** XW leaves the usage cell blank for both.
6. **Element-level detail not captured:** the HI composites, the 2100C/D INS05–INS17 (271), the MPI, the DMG05 composite and the 2100B/2120C PER element rules (only the qualifiers are listed above). These are in XW and were not transcribed here because they do not start or identify loops.
7. **Segment-level situational rules (the TR3 notes text).** XW only flags "New Situational Rule"; the rule wording is in the paid TR3.
8. **Inaccessible leads:** the Virginia DMAS MES 270/271 companion guide URL returned HTTP 404 (an HTML page). Health plan guides found by search (e.g. Florida Health Care Plans, CareSource) were not used because they are not CMS, MAC or state Medicaid sources.
