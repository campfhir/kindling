Each structure is rendered as the standard's abstract message syntax (one item per line, groups indented,
`<A|B>` for a choice of segments) and compared by shape; group names are each source's own and are not
compared. hl7.eu decides, unless Caristix and HAPI agree with each other against it; with no hl7.eu table,
Caristix and HAPI must agree. **Status** is `ok` when our structure matches the decided shape, `accepted`
when it differs by a recorded, dated decision (`codegen/validate/message-notes.json`), `differs` when it
differs and nothing records why, and `undecided` when the sources disagree and hl7.eu has no table.

In the event table each source cell says whether that source's shape matches ours: ✓ when it does, `differs` when it does not, and — when the source has no table for the event. Every structure with a `differs` cell is drawn side by side below, with the status and the dated reason where one is recorded.
