For each attribute (type, repeat, usage, length) the three values are compared. When they differ, hl7.eu
decides, unless Caristix and HAPI agree with each other against it (then they decide and the row is marked

value each source gave. Legacy datatype names (CN/XCN, TN/XTN, AD/XAD, LA1/LA2) are treated as the same type.

Columns: **Type / Rep / Usage / Len** are the decided values. **Ours** is what the class implements:
the setter names, `rep` when the setter takes repetitions, `typed` when it takes named components,
`spec` when the class is generated from `codegen/spec/<version>-segments.json`. **Class** names the version
whose class v2.3.1 uses (a re-export of an older version's class, or its own). **Status** lists open
issues (our class or spec differs from the decided value), remarks, and dated hand-written notes from
`codegen/validate/ledger-v231-notes.json`; **Sources** lists the contradictions between the sources.
