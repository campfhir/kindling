whose class v2.1 uses (a re-export of an older version's class, or its own). **Status** lists open
issues (our class or spec differs from the decided value), remarks, and dated hand-written notes from
`codegen/validate/ledger-v21-notes.json`; **Sources** lists the contradictions between the sources.
